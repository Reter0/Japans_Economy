This is a writing sample for universities admission process. The file describtion is listed below:
	- ReadMe.txt
	  Designed to describe the functions and the structure of the project within the directory

	- Outcome
	  Main file that contains the main, and the result of the paper. It is fully designed as an academic paper with
	  regards to the subjective proposal file. 

	- Data 
	  The graphs, raw data, and processed data is saved within this file. NOT encrypted and is on full access. 

	- Temp
	  Saving the drafts as unfinished scripts to work on. Should the "outcome" directory be available, the temp file
	  is obsolete and can be removed.
